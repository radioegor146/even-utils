# even-utils

My experiments with Even Realities G1 glasses and their protocol.

For now it supports:
- Custom Dashboard Map mode images
- Custom Dashboard News mode source/text/creation/deletion

Future plans:
- Fully reverse engineer Navigation mode
- Fully reverse engineer basic stuff for using this app without original Even Realities app

To use it in any way you must either patch original app so it does not send any Map/News updates, or add support for periodically sending basic Dashboard info, so it will not disconnect.

P.S. I'm not an Android developer in any way, and this code is really bad in a lot of ways.

P.P.S If someone wants to contribute or help developing stuff with their protocol, you can contact me at [re146.dev](https://re146.dev), and I will share details of the protocol (for now the docs about the protocol only exists as a single .md file)
